# Sandai League

A lightweight, single-page tournament dashboard. It works for any sport or game and shows the essentials: matches, standings, and teams.

## Run it

Open `index.html` in a browser. No installation, build step, server, or external dependency is required.

## Edit tournament information

Update the teams and matches in `js/data.js`. The dashboard automatically recalculates the summary and league standings from completed matches.

## Project structure

- `index.html` — page structure
- `css/style.css` — responsive styling
- `js/data.js` — tournament data
- `js/app.js` — small rendering and filtering logic
